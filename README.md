# 🐧 Penguin Array Lab

An Ice Age themed interactive Data Structures simulator for:

- Array address calculation
- Array insertion
- Array deletion
- Linear search
- Binary search

## Technology

- HTML5
- CSS3
- JavaScript for browser interaction and animation
- C++ for the core algorithm implementations

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

Compile the C++ reference implementation:

```bash
g++ cpp/array_algorithms.cpp -std=c++17 -o array_algorithms
./array_algorithms
```

On Windows:

```bash
g++ cpp/array_algorithms.cpp -std=c++17 -o array_algorithms.exe
array_algorithms.exe
```

## Publish as a website

Push this project to GitHub, then enable GitHub Pages from:
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

The website is static, so no server is required.
